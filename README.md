# Count Positive and Negative Numbers

## Explanation

This program counts the number of positive numbers, negative numbers, and zeros in a given list.

## Problem Statement

Write a Python program to count positive, negative, and zero values from a list of integers.

## Features

* Accepts multiple numbers
* Counts positive numbers
* Counts negative numbers
* Counts zeros
* Displays the results

## How It Works

Each number is checked:

* Greater than 0 → Positive
* Less than 0 → Negative
* Equal to 0 → Zero

## Technologies Used

* Python 3

## Data Structure Used

* List

## Methods Used

* `input()`
* `split()`
* `map()`
* `append()`

## Program Flow

1. Read numbers
2. Convert them into integers
3. Check each number
4. Update the appropriate counter
5. Display the results

## Sample Input

```text
10 -5 0 8 -2 0 7
```

## Sample Output

```text
Positive numbers: 3
Negative numbers: 2
Zeros: 2
```
